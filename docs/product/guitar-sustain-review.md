# 줄별 울림 유지 앱 반영 리뷰

2026-10-23 · 사용자 승인 · Claude 구현 / Codex 관리·독립 검증

## 목적과 청취 근거

사용자는 25초 A/B 비교 후 적용본이 더 자연스럽다고 평가하고 앱 반영을 요청했다.
근거는 `docs/product/guitar-listening-evaluation.md`, 비교 파일은 `artifacts/guitar-stroke-ring-20261022/`.
일반 스트로크에서 같은 화음의 각 줄이 다음 실제 재타격까지 울리게 하되 피치·세기·타격 시각은 보존한다.
설계는 `docs/specs/guitar/gt-004-stroke-sustain.md`.

## 구현 검토 기준

- 명시적인 "줄별 울림 유지" 버튼, 필요한 자동 줄 배정 포함. 기존 곡을 자동 변경하지 않는다.
- 동일한 화음 구성의 인접 타격만 연결한다. 화음 변경·쉼·선택 및 섹션 경계를 넘어 연장하지 않는다.
- 개별 음의 의도적인 끊음, 연주법 gate, 음소거·잠금·줄 직접 지정, 선택 밖 데이터를 보존한다.
- `assignStrings` 내부의 choke가 준비 단계에서 음을 줄이더라도 그 변경을 이번 기능의 결과에 누출하지 않는다.
- 자동 줄 배정을 포함한 전체 동작이 한 번의 Undo로 정확히 복구되고 Redo·저장/로드·재적용이 일관된다.
- 승인된 A3 AFTER의 실제 길이·타격 이벤트와 새 제품 함수 결과를 비교한다.
- 실시간 재생·MIDI·WAV는 같은 노트 데이터를 사용하며 같은 키 재타격은 off→on 순서를 유지한다.

## 코드 리뷰와 독립 테스트

- 준비용 `assignStrings`의 길이 변경은 거절하고, 필요한 줄 번호만 임시 판정에 사용한다.
- 초기 리뷰에서 A/B 타격에 untagged 노트가 섞이면 legacy 자동 스트럼의 실제 시작과 저장 시각이 달라질 수 있음을 지적했다.
  양쪽 타격 모두 명시적 스트로크여야 연결하도록 수정됐고, 혼합 타격/untagged 목적지 테스트를 확인했다.
- 초기의 타격 전체 줄 정보 기록은 보호 대상까지 건드릴 수 있어 범위를 축소했다.
  최종 구현은 실제로 연장된 음에만 자동 줄 번호를 저장한다. 유지된 88음의 JSON은 BEFORE와 동일하다.
- 변경된 기존 `lib/` 파일은 `guitar_strings.dart`(기존 산술의 공개 wrapper),
  `guitar_stroke_panel.dart`(버튼/설명/결과), `step_grid.dart`(한 번의 commit) 세 개다.
  새 순수 함수는 `guitar_sustain.dart`. 재생 엔진·모델·스키마 기본값은 바꾸지 않았다.
- Codex 독립 실행: 기타 관련 **193 통과 / 3 생성 테스트 건너뜀**, exit 0.
  로그 `artifacts/guitar-sustain-review-20261023/codex-guitar-tests.log`.
- 승인된 AFTER의 288음 길이 일치, 200음 연장, 같은-key MIDI off→on,
  화음/보이싱 변경·개별 쉼·부분/분리 선택·잠금·음소거·연주법·수동 줄 배정·충돌 보존,
  재적용 멱등성, 실제 EditScreen의 Undo/Redo/저장-로드/실시간 gate를 포함한다.
- 전체 테스트·분석·빌드의 최종 결과와 실행본 검토는 아래 기록 전까지 미완료다.

## 사용 경로와 지원 범위

기타 트랙 → 그리드 → 기타 연주 → 스트로크/패턴 적용 → 기타 연주를 다시 열어 "줄별 울림 유지".
선택이 없으면 트랙 전체, 있으면 완전한 인접 타격이 선택된 구간만 대상이다.
같은 화음의 같은 보이싱을 반복할 때 연결하며 화음 변경·쉼·연주법·잠금 등은 유지한다.
부분 화음 선택, 다른 보이싱, 아직 스트로크를 적용하지 않은 노트는 늘리지 않고 이유를 표시한다.
실행취소 한 번으로 자동 줄 배정까지 되돌릴 수 있다. "울림 되돌리기"는 길이를 되돌리고 줄 정보는 유지한다.
