# 기타 첫 단계 리뷰 게이트

2026-10-22 · Codex 관리/리뷰 · 구현과 테스트 변경은 Claude 담당

## 계획 검토에서 확인할 위험

1. **원본 복원:** gt-002의 `ringBase: double?`만으로 `dur=2, durationSteps=null`과 `dur=1, durationSteps=2.0`을 구별할 수 없다. 되돌리기는 재생 길이뿐 아니라 원래 JSON의 정밀도/nullable 표현까지 보존해야 한다. gt-001 StrokeTag 역시 기본 dur·offset·velocity null을 정확히 복원해야 한다.
2. **명시적 변환 경계:** split/chop/quantize 뒤 태그를 버리더라도 변환된 화음에 legacy auto-strum이 다시 붙지 않아야 한다. `stroke != null`만 중복 처리 방지 조건으로 삼으면 태그 제거 이후 재적용될 수 있다. velocity/offset/duration을 포함한 실제 분기와 검증이 필요하다.
3. **같은 음:** 리스트의 같은 MIDI 음을 Map으로 덮지 않는다. 모델 데이터 보존과 단일 MIDI 채널의 겹친 같은 음 출력 제약을 구분한다. 음원이 확실히 분리되지 않으면 동시에 두 음이 독립적으로 울린다고 주장하지 않는다.
4. **줄 배정:** actual start와 chord grouping을 구별한다. 스트로크로 시작점이 엇갈린 한 화음이 서로 같은 줄에 배정되지 않도록 고려한다. 동시에 울리는 음을 모두 동시 타현 화음이라고 오판하지 않는다.
5. **울림의 범위:** 선택된 음만 변환해도 다음 재타현이 선택 밖일 수 있다. 다음 같은 줄/같은 MIDI 음의 시작을 전체 트랙에서 찾아 끝점을 정하되 선택 밖 데이터 자체는 수정하지 않는 규칙이 필요하다. locked/muted 처리와 경계값을 명시한다.
6. **악기·피치 변경:** transpose, chord stamp, 비기타 트랙으로 붙여넣기 후 guitarString/stringLocked의 유효성과 잔여 stroke/ring 메타데이터를 검토한다. 잘못된 줄·프렛을 조용히 보여 주지 않는다.
7. **Groove:** 울림/choke를 변환 전 시각에서 계산한 뒤 groove가 onset만 옮기면 겹침이 재발할 수 있다. 현재 지원 범위와 렌더 이벤트의 note-off 순서를 검증한다.
8. **속도:** 6줄 배정의 조합 검색을 음마다 무제한 수행하지 않는다. 긴 MIDI, 7음 이상 화음, 잘못된 수치에 대해 UI 응답과 계산 상한을 둔다.
9. **기타 음원:** FreePats nylon 슬롯1001을 오프라인에서도 선택·설치·재생할 수 있어야 한다. 보유 샘플의 한계와 새로운 연주 스케줄링의 개선을 구분한다.
10. **재현:** reference 사운드팩 도구를 다시 실행해도 기타가 manifest에서 사라지지 않아야 한다. 기존 7개 테스트의 수치만 8개로 바꾸지 말고 기타 범위의 실제 유효한 음을 렌더해 유한·비무음 파형을 확인한다.

## 코드 리뷰 피드백과 처리

- G1 초안은 같은 정수 step의 다른 시작점 노트들을 모두 화음으로 묶었다. 빠른 단선율이 재배치될 수 있어 Claude에 수정 요청했다.
- Claude는 새 명시적 변환만 실제 시작점 기준 0.05 step 허용 오차로 묶도록 수정했다. legacy 분기는 유지했다. 빠른 멜로디/작은 타이밍 차이/재적용 테스트를 독립 실행해 통과했다.
- `playback and export read the same events` 순수 테스트는 노트 데이터와 MIDI 이벤트를 비교한다. 이 결과만으로 실제 장치 출력이나 에디터의 지연 예약 취소까지 검증됐다고 보지 않는다.
- G1 인계 보고에서 offsetSteps가 1 이상인 뒤쪽 줄을 중간 구간에서 재생 시작할 때 누락하는 한계를 확인했다. 실제 onset이 구간 안에 있는 아직 타현하지 않은 음이 빠지는 것은 seek/chase의 일반 제약과 구별하여 P1 수정 요청했다. 실제 에디터에서 부분 구간 시작·반복·정지 테스트로 닫아야 한다.
- 위 P1은 Claude 수정 후 Codex가 실제 에디터 통합 테스트를 독립 실행해 통과했다. 정수/소수 시각 시작, 일반/그루브 반복, 정지 후 예약 취소를 포함한다. 실제 장치 청취와 G2 울림까지 통과했다는 의미는 아니다.
- G2 초안 리뷰: 화음은 변환 전 시각으로 묶지만 줄 타임라인의 검색은 실제 onset 정렬이 필요하다. 느린 스트로크가 다음 화음을 넘어가는 경우와 겹친 fixed/locked 음의 긴 울림을 놓치는 경우를 Claude에 전달했다. `applyRing`의 구간 상한과 기존 긴 음 처리도 스펙에 맞추어 결정·검증하도록 요청했다. 처리 확인 대기.
- G2 핵심 로직 수정 후 56개 테스트를 독립 실행해 통과했다. 느린 스트로크의 실제 onset 정렬·고정 노트 겹침 검사, 명시적 스트로크의 줄 번호 순서(전체 배정 시), 미배정 화음의 pitch fallback과 legacy 유지가 포함된다. 울림 변환은 원래부터 구간보다 긴 음을 유지하고 새로 늘리는 길이만 상한을 지키기로 결정했다. 섹션 출력 clip은 별도로 검사한다.
