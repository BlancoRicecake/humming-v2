# 기타 G3: 팜뮤트·하모닉스 리뷰 기준

2026-10-22 · 요청: 사용자 · 구현/테스트 작성: VS Code Claude · 관리/독립 검증: Codex

## 이번 목표

기존 어쿠스틱 기타 스트로크·울림 위에 선택한 노트의 연주 표현을 지정하고 비교·원복한다.
코드와 테스트는 Claude가 작성한다. Codex는 설계를 검토하고 독립 실행 및 프로그램 리뷰를 한다.
전용 녹음 샘플이 없는 표현은 근사로 표시한다. 실제 팜뮤트/자연 하모닉스 녹음과 같다고 부르지 않는다.

## 확인할 항목

1. 기존 곡은 명시적 적용 전 동일하게 재생·저장·출력된다. 일반 연주, G1 스트로크, G2 울림을 보존한다.
2. 선택 없음/일부 선택/locked/muted 규칙을 문서화한다. 적용·일반으로·Undo/Redo·저장/로드·복사/복제에 표현 정보가 보존된다.
3. 표현 해제 시 그 사이 사용자가 고친 피치·길이·세기를 오래된 백업으로 덮지 않는다. 팜뮤트와 G2 울림의 우선순위를 정한다.
4. 하모닉스의 MIDI 피치를 기준음과 실제 발음 중 무엇으로 해석하는지 명시한다. 단순 옥타브 이동이나 가장 강한 스펙트럼 피크를 실제 기본음으로 단정하지 않는다. 범위 밖 피치를 조용히 옮기거나 버리지 않는다.
5. 일반/팜뮤트/하모닉스 음이 겹쳐도 다른 음의 음색·울림·Pan/볼륨이 바뀌지 않는다. 같은 피치 재타현, 느린 스트로크, 그루브, 빠른 연속 적용을 검사한다.
6. 기존 트랙·드럼·메트로놈 채널을 빼앗지 않는다. 유한 채널/음성 자원 부족 시 사용자에게 알리고 일관되게 처리하며 노트를 조용히 누락하지 않는다.
7. 패드/그리드 미리듣기, 라이브, MIDI, WAV, 스템에서 같은 표현 규칙을 따른다. MIDI의 GM 대체와 실제 선택 음원 차이는 구분한다.
8. Stop/seek/구간 반복/섹션 변경/트랙 삭제·Solo·Mute 뒤 예약 음과 릴리스가 남지 않는다. 비동기 음원 로딩 중 정지도 포함한다.
9. Windows Melty와 Android FluidSynth의 경로를 구분한다. 테스트와 파형 검증을 장치 청취 완료로 부르지 않는다.
10. 초보자가 `기타 연주`에서 찾을 수 있어야 한다. 간단한 선택과 적용 범위, 근사 여부를 표시하고 구현 내부 설명은 최소화한다.

## 설계 리뷰 결정

- [gt-003](../specs/guitar/gt-003-palm-mute-harmonics.md) r3: 표현은 불변 파라미터로 노트에 저장하고 원래 피치·길이·세기·줄과 G1/G2를 바꾸지 않는다. 원복은 표현만 지운다. 설정 기본값이 바뀌어도 저장한 표현은 같아야 한다.
- 전체 곡 기준 자원 계획을 라이브/미리듣기/믹스/스템에 공통 적용한다. 채널이 부족하면 적용 시 거절하고, 기존 과용량 곡은 표시와 함께 같은 fallback을 사용한다. MIDI는 발음 기준 피치·시각·길이를 유지하며 음색 손실을 알린다.
- 전용 녹음이 없는 나일론의 단순 gate/세기 감소는 팜뮤트로 완료 처리하지 않는다. 첫 팜뮤트는 일렉 계열 GM 대체임을 표시한다. 실제 나일론 팜뮤트와 자연 하모닉스 재현은 별도 자산 보강 과제다.
- 피치 측정은 파형의 배음 구조에 대한 대리 지표다. 가장 강한 주파수나 후보 배음열의 합치만으로 사람의 지각 피치가 확정됐다고 하지 않는다. 하모닉스는 검증한 음역의 음색 근사로 한정한다.
- 재사용 채널 위험을 Claude에 전달했다: Melty의 과거 drum 역할 집합, LoopAudio의 kit 캐시, 미사용 채널 Pan 초기화가 G3 채널에 남지 않아야 한다. drum → articulation → pitched 전환 회귀 검증을 요청했다.
- GM28의 실제 key-zone 밖 노트가 무음이 되는 일이 없도록 지원 범위 검사와 경계 렌더를 요청했다.
- 구현 초기 리뷰로 실제 발음 피치 기준 지원 범위 검사와 표현 노트의 paint 병합 방지를 요청했고 코드 반영을 확인했다. 회귀 테스트 통과는 별도 확인한다.
- 중간 재생(chase)은 원래 시작부터 경과한 시간을 표현 gate에서 차감해야 한다. 이미 끝난 짧은 음이 다시 살아나는 경로를 검사한다.
- 라이브는 기존 velocity 볼륨 규칙을 한 번만 적용한다. 표현 채널 CC7까지 볼륨을 중복 적용하지 않도록 0/0.5/1 경계를 요청했다.
- 같은 표현 채널·같은 피치의 연타는 앞 음의 MIDI note-off가 뒤 음을 조기에 끊지 않아야 한다. WAV/스템의 실제 렌더와 라이브를 비교한다.
- r4 승인: plain MIDI에 PM/harm을 원트랙 채널로 합치면 같은 피치의 일반 지속음을 표현 note-off가 끊는다. plan의 별도 채널에 원트랙과 같은 GM fallback program과 발음 피치 S를 기록해 겹침을 보존한다. G0~G2 출력은 불변이며 GM28/31 음색 근사는 MIDI에 담지 않는다. 기존 r3의 '모두 원트랙 채널' 규칙을 이 결정으로 대체한다.

기법 비교 참고: [Impact Soundworks Archtop 공개 매뉴얼](https://impactsoundworks.com/docs/Archtop%20Manual.pdf) p3–4. 팜뮤트의 밝기·울림 감소와 스타카토를 구분하는 행동 설명만 참고하며 코드·샘플·이미지는 사용하지 않는다.
