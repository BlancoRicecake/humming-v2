# 그리드(피아노롤) 사용성 개선 설계

2026-10-23 · 대상: `mobile/lib/looptap/widgets/surfaces/{pitch_grid_surface,step_grid,velocity_lane}.dart`, `screens/edit_screen.dart`, `state/loop_prefs.dart`

## 현재 레이아웃 (1266×714, Windows, 위젯 테스트 실측)

| 영역 | y 범위 (px) | 높이 |
|---|---|---|
| 상단바 + 섹션바 + 타임라인 헤더 | 0–115 | 115 |
| 타임라인(Arrangement) + 스크롤바 | 115–271 | ~156 |
| 분할 핸들 + 오디션 바 + 트랙 헤더 + PC 건반 힌트 줄 | 271–403 | ~132 |
| 그리드 도구 줄 | 403–443 | 40 |
| **노트 영역(세로 스크롤 뷰포트)** | 443–588 | **144** (그 안의 박자 숫자 20px은 128줄 콘텐츠 맨 아래라 실제로는 안 보임) |
| 강약 막대 + 인스펙터 줄 + 재생 바 | 588–714 | ~126 |

- 노트 행: 128음(MIDI 0–127) 고정, 최소 24px → 한 화면 4~5줄.
- 시간: 4스텝 = 1박, 16스텝 = 1마디 (`theory.dart`: `kBeatsPerBar = 4`, `kStepsPerBeat = 4`, 4/4 고정, 박자표 없음).
- 가로: 구간 전체가 항상 폭에 맞춰짐(줌/가로 스크롤 없음). 8마디 = 128스텝 → 스텝당 ~9px.

## 계획

### (1) 편집 영역 우선
- **편집 확대** 토글(`grid-focus`; 넓은 화면은 트랙 헤더의 패드/그리드 옆 알약 버튼, 폭 700px 미만은 그리드 도구 줄 맨 앞 아이콘): 켜면 그리드 모드에서 타임라인을 한 줄(28px) 바로 접고, PC 건반 힌트 줄(40px)을 숨기고, 보조 도구를 한 줄로 합친다. LoopPrefs `gridFocus`(UI 설정만 저장).
- **타임라인 접기/펼치기**(데스크톱 타임라인 헤더 + 접힌 줄의 펼치기 버튼, `timeline-collapse`): LoopPrefs `timelineCollapsed`. 접힌 상태에서는 분할 핸들도 없다. 펼치면 기존 분할 비율·드래그·더블클릭 초기화 그대로.
- **도구 두 줄로**(`note-tools-more`, 선택 편집 모드): 기본은 도구 + 인스펙터를 한 줄(가로 스크롤)로 합치고, 켜면 기존처럼 두 줄. 도구 줄 앞쪽 순서는 기존 그대로: (기타 연주) 입력 · 선택 편집 · 영역 선택 · 지우개 · 복사 · 붙여넣기 … (기존 테스트가 직접 누르는 버튼 위치 보존). LoopPrefs `gridToolsExpanded`.
- **강약/확률 막대** 토글(`note-velocity-toggle`)은 그대로, 상태만 LoopPrefs `gridVelocityLane`에 저장(기본 켜짐).
- 행 최소 높이는 기존 24px 유지(기존 테스트 기준).
- 모바일 레이아웃(타임라인 2 : 표면 3)은 유지. 편집 확대를 켤 때만 타임라인을 접는다.

### (2) 시간 눈금
- 노트 바로 위 **고정(sticky) 눈금**(22px): 세로 스크롤과 무관하게 항상 보이고 가로 줌/스크롤을 따른다.
- 마디 번호(마디선 위치), 박 눈금(중간), 16분 눈금(짧게, 픽셀 충분할 때만). 글자 폭을 실제 측정해 `stride`(1,2,4,8…마디)로 솎아 겹치지 않게 하고, 오른쪽 끝을 넘는 라벨은 그리지 않는다. 박 번호(1.2, 1.3 …)는 박 간격이 충분할 때만.
- 그리드: 마디선 강하게(밝은 2px), 박선 중간, 16분선 약하게. 검은 건반 행은 어둡게, C 행 위에 옥타브 구분선.
- 기존 바닥 박자 숫자 줄(실제로는 안 보이던 것)은 제거.
- 가로 줌: 눈금 왼쪽 모서리 −/+ 버튼, Ctrl+휠, 눈금 더블클릭 = 전체 보기. 확대 시 노트 아래 가로 스크롤 막대. Shift+휠/가로 휠 = 가로 이동. 일반 휠 = 기존 세로(음높이) 스크롤 그대로.

### (3) 피아노 건반 거터
- 왼쪽 거터: 기존 ▲/▼ 레일(13px) + 건반(40px) + 간격 4px. 흰/검은 건반 모양, 모든 C에 `C4` 식 이름(앱 표기와 동일: MIDI 60 = C4), 행 높이가 충분하면 흰 건반 전부 표시.
- 거터는 노트와 같은 세로 스크롤 뷰 안에 있어 행이 정확히 맞는다.
- 건반 클릭 = 미리 듣기(`onPreview`)만, 노트 추가 없음. 세로 드래그 = 기존 음높이 창 이동(24px당 1칸, 0..max) 그대로.

### (4) 선택 노트
- 선택 노트: 밝은 흰색 채움 + 바깥 테두리 2px(어두운 분리선 포함) + 트랙색 아래 줄 + **오른쪽 끝 손잡이만**(StepGrid는 오른쪽 끝에서만 길이 조절; 왼쪽 끝은 테두리로만 표시, 왼쪽 자르기 기능 없음). 아주 짧은 노트는 위에 ▼ 표시를 추가. 선택 노트는 나중에 그려 가려지지 않는다.
- 뮤트(속 빈) 노트가 선택되면 흰 테두리 + 손잡이(채움 없음). 잠김(호박색 점), s / PM 점선 / ◇, ↓/↑, 줄 번호는 선택 시 글자색만 어둡게 바꿔 계속 읽힌다.
- 비선택 노트에 얇은 어두운 외곽선을 넣어 붙은 노트도 구분.
- 영역 선택 사각형: 흰 점선 테두리 + 옅은 채움.

## 좌표계 규칙 (단일 출처)

`PitchGridAxis`(pitch_grid_surface.dart) 하나만 x/y를 계산한다.
- `x(step) = (step − view.start) / view.length × laneWidth` (`TimelineView`와 같은 투영), `stepAt(x)`는 역함수.
- `y(row) = row × rowHeight`, `rowAt(y)`; `rowHeight = laneContentHeight / rows`.
- `gutterWidth` = 레일 13(있을 때) + 건반 40 + 4.
- 사용처: 그리드 페인터, 눈금, 플레이헤드, 드래프트, 히트 테스트(`GridPointer.axis`), StepGrid의 노트 히트/리사이즈 판정/영역 선택, VelocityLane(`leftInset = gutterWidth`, 같은 `TimelineView`).
- `pitch-grid-lane` 키는 계속 "노트 영역 콘텐츠"(거터·눈금 제외)를 가리킨다. 줌 1에서는 `rect.left + width × step / steps` 공식이 그대로 성립(기존 테스트 호환).

## 보존

노트 데이터(음높이·세기·미세 타이밍·확률·잠김/뮤트·G0–G4 필드), 편집 동작(입력/선택/이동/길이/복사/붙여넣기/삭제/Undo/Redo/키보드 단축키), 휠 세로 스크롤, 라벨 드래그 음역 이동, 데스크톱 분할 핸들(드래그/더블클릭 초기화), 모바일 레이아웃, 재생/MIDI/WAV. 노래 데이터 형식 변경 없음(LoopPrefs UI 설정만 추가).
