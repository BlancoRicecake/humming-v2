# 결정에 쓰는 핵심 시사점

조사일 2026-10-12 · 원문과 전체 출처는 `raw/` · ✅ = 이 세션에서 원문 페이지로 재확인 · `[미확인]` = 단일·약한 출처

각 항목 끝의 **→** 는 HumTrack의 어떤 결정에 영향을 주는지다. 여기 적힌 것은 판단 재료이지 결정이 아니다. 결정은 Heo가 하고 `context-notes.md`에 남긴다.

## A. "경제적 장벽"이라는 이유에 대해

1. **늘어나는 건 '취미·캐주얼' 창작자다.** 음악 창작자(생성형 AI 사용자 포함)는 2020→2025년 +167% 늘어 1억 4,870만 명. 같은 기간 전통 연주자는 +33%. ([MIDiA, 2026-07](https://midiaresearch.com/blog/the-future-of-the-music-creator-economy))
   → 초보자 우선 결정과 일치한다.
2. **장벽은 돈만이 아니다.** 영국 청소년 2,100명 조사(2024)에서 비용(레슨이 비싸다 21%, 악기가 비싸다 19%), 시간(공부 19%), 자신감("노래를 못한다" 18%, 시도할 자신이 없다 15%)이 비슷한 크기. 저소득층 아이는 스스로를 '음악적'이라고 보는 비율이 51%로 고소득층(63%)보다 낮다. ([Youth Music 2024](https://youthmusic.org.uk/sites/default/files/2024-07/Youth%20Music%20Sound%20of%20the%20Next%20Generation%20report_0.pdf))
   → 메시지는 "싸다"보다 **"돈도, 장비도, 실력도 없이"**. 경제적 장벽을 풀려면 자신감 장벽도 같이 풀어야 한다.
3. **신흥국에서는 폰이 유일한 기기다.** 컴퓨터가 있는 가구는 인도 10% 미만, 인도네시아 18.5%. 최소 작업 환경(인터페이스 + DAW, 약 $600)은 인도 월소득 2.7개월치, 나이지리아 5.8개월치(추정). 사하라 이남 아프리카 모바일 인터넷 사용자의 60%는 아직 3G·피처폰. ([GSMA 2025](https://www.gsma.com/somic/wp-content/uploads/2025/09/The-State-of-Mobile-Internet-Connectivity-2025-Overview-Report.pdf), raw/market)
   → "비싼 장비 없이"를 진짜로 지키려면 **저사양 안드로이드, 작은 설치 용량, 적은 데이터 사용**이 기능만큼 중요하다.
4. **같은 $3.49도 나라마다 무게가 다르다.** 월 1인당 소득 대비 미국 0.05%, 일본 0.1%, 인도 1.6%, 나이지리아 3.4%. Spotify는 미국 $11.99, 인도 $1.59, 나이지리아 $1.04로 받는다. Apple은 175개 스토어별 가격 조정을 지원한다. (raw/market)
   → **지역별 가격**이 "비용 걱정 없이"를 지키는 가장 직접적인 수단이다.

## B. 무료 범위와 수익 (로드맵 4장 열린 질문)

5. **내보내기를 유료로 막는 곳은 DAW 계열에서 거의 없다.** BandLab은 공식 문서상 무료로 WAV·MIDI 내보내기, GarageBand는 무료, FL Studio Mobile·Koala·Ableton Note는 1회 결제에 내보내기 포함. 내보내기를 막는 곳은 Suno 같은 AI 생성기(무료 평생 7회, 개인 용도만)이고 비판받고 있다. (raw/competitors)
   → 현재 "무료는 앱 밖으로 못 꺼냄"은 업계 기준에서도, 비전에서도 가장 약한 지점이다.
6. **그러나 무료를 넓히면 전환율은 떨어진다.** 다운로드→결제(35일) 중앙값은 하드 페이월 10.7%, 프리미엄 2.1%. 1년 유지율은 비슷. 저가 앱은 전환율이 1.4%로 고가 앱(2.8%)의 절반. ([RevenueCat 2026](https://www.revenuecat.com/state-of-subscription-apps))
   → 중간안이 근거를 얻는다. **무료 = 공유용 짧은·워터마크 내보내기, 유료 = 원본 품질 WAV·MIDI·스템.** 무료 공유물이 틱톡 유입 채널(이미 일본에서 작동)이 된다.
7. **연간 플랜과 긴 체험이 유리하다.** 12개월 유지율 연간 44% vs 월간 17%. 17~32일 체험의 전환율 45.7% vs 짧은 체험 26.8%. 체험 시작의 82%가 설치 당일. ([RevenueCat 2025](https://revenuecat.com/state-of-subscription-apps-2025))
   → 7일 체험을 연간 플랜 14일 이상으로 늘리는 실험 후보.

## C. 경쟁 구도

8. **BandLab이 이미 핵심 기능을 갖고 있다.** 1억+ 사용자. 목소리·악기 → MIDI 변환(Audio-to-MIDI)은 **멤버십 전용** ✅([BandLab 도움말](https://help.bandlab.com/hc/en-us/articles/37575596722329-Converting-Audio-to-MIDI)), 기존 MIDI에 코드·베이스·드럼을 붙이는 Layer도 멤버십. 멤버십은 월 $14.99.
   → HumTrack의 차별점은 기능 자체가 아니라 **"쉬움 + 모바일 우선 + BandLab의 1/4 가격 + 내 멜로디라는 소유감"**.
9. **BandLab이 수익화를 조이고 있다.** 2026-05 업데이트에서 무료 샘플 제한·광고를 늘려 해당 버전 평점이 4.19→2.76 `[단일 출처: mwm.ai]`. 일본에서 Studio를 여는 데 멤버십을 요구하는 테스트 중이라는 고객센터 답변이 일본 App Store 리뷰에 있다 `[단일 출처, 미확인]`.
   → 사실이면 **일본에서 대체재를 찾는 사용자가 생기는 시기**다. 재확인 1순위.
10. **'허밍 → 곡' 전용 앱은 비어 있다.** HumToSong(iOS, 1천 회 미만, ★2.6), EveryBit(Android, 5천 회, ★3.1), ByteDance Ripple(2023 미국 베타 후 소식 없음 `[미확인]`).
    → 이 니치에 제대로 된 제품이 없다.
11. **"노래 하나 갖고 싶다"는 수요는 AI 생성기가 무료로 흡수 중이다.** Suno(사용자 1억·연매출 약 $3억 주장 `[미확인]`), Gemini Lyria 3.5(2026-09, 최대 3분, 무료), CapCut AI 음악, ElevenMusic(무료 하루 7곡).
    → 즉석 생성으로 경쟁하지 않는다. **"네 멜로디, 네 곡, 네 소유"**로 선을 긋는다.
12. **가장 가까운 신규 경쟁자는 Mozart AI**(목소리 아이디어로 시작하는 AI DAW, 초보자 대상, 모바일 앱, 2026-02 시드 $6M). Audiotool 3.0(무료 브라우저 DAW, 실시간 공동작업, 모바일 앱 예정)도 주시. → `watchlist.md`

## D. 기술

13. **허밍은 노래·악기와 다른 문제다.** HumTrans 기준 음표 정확도(F1) Basic Pitch 0.27, 허밍 전용 모델 0.65. ([arXiv 2410.05455](https://arxiv.org/html/2410.05455v1))
    → Basic Pitch를 기본값에서 뺀 판단이 맞았다. 다음 비교 후보는 FCPE·RMVPE·SwiftF0 + **음표 단위 DP/Viterbi 정리**. 레가토 과분할을 잡을 가능성이 가장 큰 건 정리 단계다.
14. **허밍 분석을 폰에서 돌려 서버비를 줄일 수 있다.** SwiftF0(MIT, 파라미터 1.4만 개, CPU 한 코어에서 실시간의 180배)과 flutter_onnxruntime(MIT, 6개 플랫폼). (raw/open-source)
    → 사용자가 늘수록 커지는 서버비 문제의 근본 해법 후보.
15. **오디오 엔진을 하나로 합칠 길이 있다.** miniaudio 또는 flutter_soloud(둘 다 허용적 라이선스, Windows 포함) + TinySoundFont(MIT). iOS 언더런(Dart가 PCM을 밀어 넣는 구조), Android 동시발음 64개 제한, Windows 전용 WASAPI 코드를 한 번에 없앨 가능성. `[실험 전 가설]`
    → 데스크톱 트랙과 겹치는 큰 결정. 작은 실험(스파이크)부터.
16. **라이선스 확인이 필요한 곳이 있다.** flutter_midi_pro는 Android에서 FluidSynth(LGPL-2.1)를 쓴다 ✅([pub.dev](https://pub.dev/packages/flutter_midi_pro)). LGPL 고지·소스 제공·교체 가능한 라이브러리 형태가 필요하다. 번들 사운드폰트 출처도 점검(GeneralUser GS·MuseScore General·FluidR3는 괜찮음, Sonatina·Spitfire LABS는 피함). AGPL/GPL(Essentia, aubio, 무료 JUCE, Vital)은 가져오지 않는다. (2026-10-12 결정, Heo: **지금 고지 보강**. 앱 라이선스 화면에 FluidSynth LGPL 전문·소스 위치와 누락됐던 CC-BY 사운드폰트 크레딧을 추가하는 코드 작성 — `mobile/lib/services/third_party_licenses.dart`)
17. **최근 지원이 끝난 부품.** Superpowered(2027-07 종료), FFmpegKit·sfizz·Magenta note-seq(2026 보관 처리). 새로 쓰지 않는다.
18. **YuE 라이선스가 바뀌었다.** 코드와 가중치 모두 Apache-2.0 ✅(2025-01-30, [GitHub](https://github.com/multimodal-art-projection/YuE)). `docs/AI_ARRANGEMENT_ROADMAP.md`의 "가중치 CC BY-NC" 서술은 낡았다. 단, 학습 데이터 출처가 공개되지 않아 법적 위험은 남는다(아래 E). (2026-10-12 결정, Heo: **실험 후보**로 올림. 내부 계정·AI 표시 조건, 출시 관문은 그대로. 로드맵 문서 정정 완료)

## E. AI·법률

19. **소송의 초점은 '학습 데이터 출처'다.** UMG·Sony가 Suno를 다시 제소(2026-09-18), 독일 GEMA가 Suno에 승소(2026-07-31). 미국 저작권청은 "프롬프트만으로는 저작권이 없고, 사람의 창작이 드러난 부분은 보호된다"는 입장. (raw/pitch-ai-legal)
    → **HumTrack 구조 자체가 강점이다.** 허밍한 멜로디 = 사람의 창작, 규칙 기반 반주 = 학습 데이터 위험 없음. "긁어 온 데이터 없이, 네 멜로디로"를 내세울 수 있다. 생성형 AI를 붙인다면 학습 데이터가 깨끗한 것만(Stable Audio Open 등).
20. **AI 생성물 표시 의무가 시작됐다.** EU AI Act 50조(2026-08-02, 기존 시스템은 2026-12-02 `[세부 미확인]`), Spotify·YouTube·TikTok도 표시 요구. 실존 인물 목소리 복제는 금지 추세(Spotify 정책, 테네시 ELVIS Act).
    → 내보내기 메타데이터에 "어느 부분이 사람·규칙·AI인지" 기록. 목소리 복제 기능은 만들지 않는다.

## F. 함께 노는 공간 (장기 비전)

21. **'협업 자체가 제품'인 서비스는 대부분 죽거나 팔렸다.** Endlesss·Blend(2024 종료), Splice Studio(2023 종료), Drooble(2022 종료), Soundtrap·Vampr(매각). 살아남은 곳은 **혼자 쓰는 도구 + 홍보·배포**(BandLab) 또는 콘텐츠 판매(Splice). (raw/collaboration)
    → 순서가 맞다. 혼자 쓰는 도구를 먼저 탄탄하게.
22. **커지는 협업은 '남의 씨앗에 한 겹 얹기'다.** Smule 듀엣, TikTok 듀엣(바다 노래 열풍), 라따뚜이 틱톡 뮤지컬(작곡·안무·무대·포스터를 수천 명이 나눠 만들고 제작자가 크레딧·보상). 실시간 공동 편집은 사업으로 버틴 사례가 없다.
    → 공간의 첫 형태는 **"허밍 씨앗 공개 → 누군가 노래·커버·영상을 한 겹씩 얹기"**.
23. **크레딧·분배가 비어 있다.** BandLab도 지분을 정리해 주지 않는다. Kompoz는 시작 전에 분배를 합의하고 자동 지급, DistroKid는 분배·선지급 회수 지원.
    → 처음엔 돈 없이 **역할별 크레딧 기록**부터. 분배는 외부(DistroKid 등)로 내보내기.
24. **한국 법인으로는 해외 크리에이터에게 직접 돈을 보내기 어렵다.** Stripe 크로스보더 지급은 플랫폼이 미국·영국·EEA·캐나다·스위스에 있어야 한다 ✅([Stripe 문서](https://docs.stripe.com/connect/cross-border-payouts)).
    → 유료 매칭·수익 배분은 뒤로. PayPal·Payoneer 또는 해외 법인을 그때 검토.
25. **일본 문화가 비전과 거의 같은 모양이다.** 보카로P(작곡) → 우타이테(노래) → 일러스트·MV 제작자가 함께 만드는 생태계에서 요네즈 켄시, YOASOBI의 Ayase, Ado가 나왔다. 일본 음악 앱 세션의 79%가 iOS. (raw/market)
    → 첫 글로벌 시장과 첫 '공간' 실험지로 일본이 유력하다.
26. **신뢰가 생존을 가른다.** 서비스가 닫힐 때 사용자가 작업물을 꺼낼 수 있어야 하고(Endlesss 종료 때 며칠의 유예만 있었음), AI 학습 사용은 명시적 동의(opt-in)여야 한다(SoundCloud 2025 약관 역풍).
