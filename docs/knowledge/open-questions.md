# 아직 모르는 것 (다음 조사 대상)

2026-10-12 조사에서 도구 한도·자료 부족으로 확인하지 못한 것. 관련 결정을 하기 전에 먼저 조사한다.

## 결정에 직결되는 것 (먼저)

- [ ] **BandLab 일본 Studio 멤버십 필수 테스트** — 사실인지, 범위·시기 (출처가 App Store 리뷰 하나뿐)
- [ ] **지역별 결제 수단** — 인도·인도네시아·나이지리아의 Google Play 통신사 결제, UPI, 전자지갑 지원. 카드 보유율(World Bank Findex)
- [ ] **지역 장르별 반주 요구** — J-pop·보카로, 라틴, 아프로비츠, 당둣, 인도 음계를 규칙 기반 반주로 어디까지 만들 수 있나
- [ ] **HumTrack 현재 무료→유료 전환율·국가별 설치** — 외부 벤치마크와 비교할 우리 숫자 (Firebase 수집 켜진 뒤)

## 기술

- [ ] FCPE·RMVPE 가중치의 상업 사용 라이선스
- [ ] PESTO(LGPL-3) 가중치를 앱에 넣을 때의 의무
- [ ] 현재 번들 SoundFont 파일의 실제 출처와 라이선스 (저장소 `CREDITS-soundfonts.md`와 대조)
- [ ] Android 빌드에서 FluidSynth가 동적 라이브러리(.so)로 들어가는지
- [ ] Yjs/Automerge의 Dart 연동 방법 (협업 단계에서)
