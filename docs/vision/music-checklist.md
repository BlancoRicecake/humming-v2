# HumTrack 음악 기능 개발 체크리스트

작성일: 2026-10-13 · 기준: [개선 계획](MUSIC-IMPROVEMENT-PLAN.md) · 근거: [제품 검토](MUSIC-PRODUCT-REVIEW-2026-10-13.md) · 상위 진행: [기존 체크리스트](checklist.md)

음악 기능 진행 상태는 이 파일에서 관리한다. M0~M3는 음악 개선 우선순위이고 기존 Phase를 대체하지 않는다. 모든 개발 항목은 미완료 상태에서 시작한다. 기존 기능은 새로 구현할 일이 아니라 개선 시 보존·회귀 검증할 대상이다.

## 착수와 공통 완료 조건

- [ ] 착수 시 기준 브랜치·커밋·버전과 관련 코드의 변화 확인
- [ ] 약속 Pro 기능 작업과 충돌하지 않는 작업 범위·브랜치 정하기
- [ ] 해당 ID의 재현 사례·최소 변경·기대 행동·제외 범위 기록
- [ ] 저장 포맷 변경 시 구 파일 읽기·기본값·마이그레이션·되돌리기 검증 정의
- [ ] 변경 영역에 필요한 자동 검증과 실제 기기·청취 과제 정의
- [ ] 완료 ID별 커밋·검증 결과·남은 한계를 아래 완료 기록에 추가

## M0 결과 신뢰와 Phase 0 연결

### M0-01 MIDI 스윙 보존

- [ ] 현행 파일로 스윙이 누락되는 재현 사례 기록
- [ ] 내보내기 화면 → `exportMidiSong` → `buildMidi`에 스윙 전달
- [ ] 스윙 0·중간·최대에서 짝수/홀수 step의 note-on tick 검증
- [ ] 멜로디·베이스·드럼·추가트랙·기타 스트럼과 전체곡/구간 출력 검사
- [ ] 기존 곡 저장·복원 후 타이밍 유지, 외부 MIDI 재생으로 청취 확인

### M0-02 효과 취소 일치

- [ ] 효과 2개 이상 적용 후 첫/중간/마지막 노드 삭제를 재현
- [ ] 남은 체인 재처리 또는 명확한 전체 초기화 동작을 설계에 기록
- [ ] 원본 파일 보존, 목록·현재 오디오·미리듣기·WAV의 일치 구현
- [ ] 처리 실패·취소·화면 종료·늦은 응답에서 이전 상태 보존 검사
- [ ] 저장·재실행과 효과 전체 제거 후 원본 청취 확인

### M0-03 반주 표시 일치

- [ ] major·minor·dorian·pentatonic, 2·4마디의 실제 생성 음표와 표기 비교
- [ ] 실제 구간 길이에 해당하는 코드·반복만 표시
- [ ] 음계별 코드 성질과 펜타토닉 화음 규칙을 명시하고 표기에 반영
- [ ] EN/KO 문구·후보 미리듣기·적용·Undo·저장 회귀 확인

## M1 첫 창작 단순화와 Phase 1 연결

### M1-01 가이드 흐름과 용어

- [ ] 기존 초보자 관찰 과제에서 입력·검토·반주·저장 단계의 막힘 기록
- [ ] 흥얼거리기·녹음 가져오기·직접 연주의 공통 검토/확정 흐름 설계
- [ ] 멜로디·반주·리듬·목소리 중심 표현, 상세 트랙 접근 유지
- [ ] 원본 비교·Undo·저장 상태·오류 복구를 첫 흐름에서 발견 가능하게 유지
- [ ] 게스트 진입·작은 화면·텍스트 확대·EN/KO·상세 편집 전환 확인
- [ ] 기존 기준인 초보자 5명 중 4명/3분 저장과 최대 이탈 단계를 재관찰

### M1-02 추천 음색과 후보 비교

- [ ] 기존 악기 분류·즐겨찾기를 유지하는 역할별 추천 세트 선정·청취
- [ ] A/B/C를 같은 구간·음색·음량 조건으로 비교하는 재생 정의
- [ ] 후보 설명을 실제 화음·리듬·밀도 차이와 연결
- [ ] 빠른 후보 전환·적용 전 원본 유지·Undo·저장 검증
- [ ] 랜딩 설명·예시는 출시 확인된 기능과 결과만 사용, SoundLab과 제품 웹 구분

## M2 멜로디 보존과 Phase 2 연결

### M2-01 평가 세트와 원본 계약

- [ ] 녹음 수집 동의·보존 위치/기간·삭제·분석 전송 범위를 정하기
- [ ] 튜닝용과 확인용 세트를 분리하고 정답·허용 오차·기준선 저장
- [ ] 장·단조·키 불확실·반음·반복음·긴 음·마디 걸침·도약·쉼·엇박 포함
- [ ] 원본 오디오·분석 피치·시각·길이·보정 결과·출처를 구분하는 데이터 계약
- [ ] 구 저장 파일 호환과 직접 허밍/보컬 변환의 원본·임시 파일 소유권 정의
- [ ] SongSpec·백엔드·재생·출력으로 전달할 정보와 단위를 문서화

### M2-02 보정 선택과 음역 독립

- [ ] 원본 허밍·분석된 원음정·보정 결과의 비교 의미와 UI 문구 정의
- [ ] 그대로·약한 정리·그리드 정리의 실제 처리와 가역적인 비교 구현
- [ ] 키가 불확실한 입력의 원본 유지·후보 선택·수동 키 설정 검사
- [ ] 패드 화면·옥타브·표시 창 이동이 저장된 음표를 바꾸지 않는지 검사
- [ ] 넓은 도약과 경계 음역 입력에서 멜로디 윤곽 보존 확인
- [ ] 확인용 세트 오류와 사용자 수정 횟수를 기준선과 비교

### M2-03 선택음 수정과 자유 입력

- [ ] 높은 신뢰도 음도 선택해 음정·위치·길이를 수정할 수 있게 연결
- [ ] 반음 단위 수정·보정 해제·음계 밖 입력, 분할·병합·옥타브 동작 통합
- [ ] 원본 비교·멜로디 잠금의 생성 보호와 수동 편집 의미를 구분
- [ ] Undo·Redo·저장·복원·재생·MIDI/WAV의 수정 결과 일치 검사
- [ ] 초보자 과제에서 원하는 음의 수정·되돌리기 성공 기록

## M3 완성하고 들려주기와 Phase 3 연결

### M3-01 코드와 베이스와 보이싱

- [ ] 화음/꾸밈 역할·잠금·기존 `melodyDec` 데이터 보존 방법 정의
- [ ] 지속 시간·강박·마디 걸침·프레이즈 끝·경과음의 적합성 평가 설계
- [ ] 작은 후보 집합부터 순위 평가하고 코드에 연결되는 베이스 구현
- [ ] 공통음·이동 거리·악기 음역·멜로디 음역을 고려한 보이싱
- [ ] 잠금·수동 꾸밈·원본 멜로디 보존과 적용·Undo·저장 검증
- [ ] 동일 음량 조건의 기존/개선 비교에서 음악가·초보자의 선택과 이유 기록

### M3-02 강약과 미세 타이밍

- [ ] 음표·드럼별 강약·타이밍 단위와 구 곡 기본값·호환 정의
- [ ] 원본/편집/재생 값 구분, 스윙 중복 적용과 MIDI 반올림 정책 정의
- [ ] 악기·패턴·프레이즈별 결정 가능한 강약·그루브 프리셋
- [ ] 재생·MIDI·WAV·스템에서 타이밍·강약이 같은 의미로 적용됨을 검사
- [ ] 정렬 강도 변경·Undo·재실행 후 결과 유지와 청취 비교

### M3-03 구간 전개와 끝맺음

- [ ] 시작·중심·변화·끝 역할과 자유 구성의 선택 UI 정의
- [ ] 공유 반복과 독립 복제의 수정 범위·저장 의미 명시
- [ ] 악기 추가/생략·짧은 변형·필인/쉼·끝맺음을 작은 범위로 구현
- [ ] 생성 시 잠금·수동 구간·멜로디 보존, 구간 이동·반복·Undo 검사
- [ ] 전체곡 재생·저장 복원·출력에서 전개와 끝이 일치하는지 청취
- [ ] 짧은 루프에서 의도적인 변화와 끝을 만드는 사용자 과제 기록

### M3-04 밸런스와 스테레오 전달

- [ ] 현재 모노 출력 의미와 MIDI의 외부 음색 차이를 안내
- [ ] 솔로·기본 음량·클리핑 방지와 비교 레벨 정책 정의
- [ ] 좌우 채널·팬·출력 형식·공간효과의 보존 범위 정의 및 구현
- [ ] 스템 시작점·길이·꼬리·음량 정책과 재결합 결과 검사
- [ ] 일반 파일 저장·재탐색·재공유·Pro 권한 회귀와 외부 DAW 확인

### M3-05 창작 학습과 버전 비교

- [ ] 한 요소만 바꾸기·악기 빼고 듣기·끝 두 음 바꾸기 같은 짧은 과제
- [ ] 원본/변형본 버전 비교·복원·저장·복제 동작 설계 및 구현
- [ ] 취향을 단일 정답으로 채점하지 않는 안내, 강제 학습 없이 건너뛰기
- [ ] 원하는 변화의 성공·재사용을 관찰하고 기존 퍼널과 구분해 기록
