**코딩·충돌 해결·관련 테스트는 Claude**, 운영 적용 이력·배포/버전 증빙·삭제 메타데이터
조사·최종 독립 검토는 Codex가 담당한다. 같은 파일을 동시에 고치지 않는다.

## 이번 통합 기준

1. **출시 메모14개 삭제는 의도한 정리가 아니다.** 기존 경로의 파일시스템 오류 때부터
   보존해 온 삭제 표시다. 삭제를 통합/커밋에 포함하지 않는다. 문제 폴더를 삭제·이동하거나
   디스크 수리 명령을 실행하지 않는다. 원격 develop의 정상 파일을 유지하는 별도 작업 공간으로 우회한다.
2. **pubspec의1.0.14+44는 유지한다.** 실제 Android 내부 테스트에 업로드한 버전이며,
  43으로 되돌리면 안 된다.44는 사용된 번호다. 이후 내용이 달라진 AAB를 올리려면45 이상이
   필요하지만 이번 통합 단계에서 스토어 업로드·임의 버전 올림은 하지 않는다.
  44.txt는 내부 업로드가 changelog 업로드를 건너뛰므로 없어도 업로드가 가능했다.
   실제44 검증 기록에 근거한 짧은 내부 테스트용 메모를 건강한 작업 공간에 추가할 수 있다.
3. **출시 준비 코드도 통합 후보에 포함해 리뷰한다.** 백엔드 클라우드/보안·native/runtime,
   인프라·CI·Windows runner·스토어 문구·랜딩·릴리스 문서를 기능별로 나눠 검증한다.
   리뷰되지 않은 변경까지 일괄 승인했다는 뜻은 아니다. 별도 지식 메모·Ableton 조사 도구·
   임시 자료·시크릿·산출물은 보존하고 통합 제외 목록으로 명시한다.
4. **paywall은 원격의 출시 채널/스토어 기능 구분을 유지하면서 서버 Pro 새로고침을 결합한다.**
   단순히 macOS 전체를 비스토어로 취급하면 안 된다. Mac App Store판에는 지원되는 결제/
   복원을 유지하고, Windows/Linux/Mac 직접판에는 스토어 결제/복원을 숨기되 로그인 후
   서버 구독 상태 새로고침을 제공한다. 모바일의 기존 결제·복원도 유지한다.

## Claude가 수행할 코딩 작업

- 시작 전 최신 원격과 현재 작업 상태를 확인한다. 기준으로 조사된 origin/develop은
  `d1dfb24`이고 현재 작업 폴더 HEAD는 `4f5f34d`다. 원격이 바뀌면 최신 값을 다시 기록한다.
- 사용자의 현재 작업 폴더·미커밋 파일을 권위 있는 원본으로 보존한다. stash/reset/clean이나
  현재 체크아웃 변경으로 원본을 치우지 않는다. `.worktrees/` 아래 별도 통합 브랜치/작업
  공간을 원격 develop 기준으로 마련하고 현재 변경을 누락 없이 재현한다.
  임시 사본·패치·테스트 로그도 모두 C:/src/humming-v2 안에 둔다.
- 통합 대상/보류/제외 파일을 먼저 구분한다. 기능 단위로 분리해 리뷰할 수 있게 준비한다.
 14개 메모 삭제와 독립 작업은 통합 패치에서 제외한다.
- paywall 충돌을 기능 의미대로 해결하고 번역을 재생성한다. 모바일, Windows, Mac 직접판,
  Mac App Store판의 버튼 노출/서버 새로고침/오류·중복 동작 방지 회귀를 확인한다.
- 두006은 파일 전체 이름과 적용 이력으로 구분한다. **적용된 파일을 임의로 개명하거나
  운영/스테이징 SQL을 다시 실행하지 않는다.** 현재 적용 도구가 전체 파일명 명시 목록을
  쓰는지 확인하고, 숫자006 하나만으로 잘못 선택하지 못하도록 문서/도구/실제 DB 테스트를
  보완한다. 두 기능이 같이 적용되는 격리 PostgreSQL에서 권한·스키마를 확인한다.
- Windows의 ffmpeg 미설치 실패를 그냥 기존 문제로 면제하지 않는다. 프로덕션 자격 증명
  없이 올바른 디코더가 있는 Linux 후보/격리 PostgreSQL에서 전체 백엔드 테스트를 확인한다.
  이전 검증 결과는 아래와 같지만, **이번 통합 소스의 새 결과**를 남겨야 한다.
- CI 변경의 검증 전용 성격을 유지한다. develop push가 운영 배포·스토어 업로드·마이그레이션
  실행·고객 공지로 이어지지 않는지 확인한다. main이나 공개 배포 흐름을 수정하지 않는다.
- 최종 파일 목록, 제외 목록, 충돌 해결 내용, 테스트 명령/결과/skip 사유, 남은 사람 검증을
  `artifacts/develop-integration-2026-11-03/` 또는 이 문서 옆 결과 파일에 남긴다.
- **아직 push·PR·main 병합·스토어 업로드·운영 배포·공지 게시 금지.** 로컬 통합과
  기능별 로컬 커밋은 가능하되, 완료 시 Codex 독립 검토를 기다린다. 사용자의 기존 루트
  브랜치/미커밋 작업과 파일시스템 오류 경로는 그대로 보존한다.
